# Backend Scripts

This folder contains utility and migration scripts used during development.

## Migration Scripts (Run Once)

- `create_reviews_table.js` - Creates the reviews table for detailer ratings
- `create_customer_reviews_table.js` - Creates the customer_reviews table for customer ratings
- `add_created_at_to_services.js` - Adds created_at column to services table

## Testing Scripts

- `test_*.js` - Various testing scripts for API endpoints
- `create_test_*.js` - Scripts to create test data

## Utility Scripts

- `check_*.js` - Database schema inspection scripts
- `reset_customer_password.js` - Password reset utility

**Note:** These scripts are for development/debugging only and are not required for the app to run.
